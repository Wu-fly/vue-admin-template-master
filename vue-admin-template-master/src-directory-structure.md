
# src 目录结构职责说明

```
src/
├── api/                    # API 接口层
│   └── 职责：封装后端 API 调用，统一管理接口地址和请求逻辑
│
├── assets/                 # 静态资源目录
│   └── 职责：存放项目所需的静态资源（图片、字体、音频等）
│
├── components/             # 通用组件库
│   └── 职责：可复用的基础 UI 组件，供多个页面调用
│
├── icons/                  # 图标资源管理
│
├── layout/                 # 布局组件
│   └── 职责：定义系统整体布局结构，包含侧边栏、顶部栏和主内容区
│
├── router/                 # 路由配置
│   └── 职责：管理页面路由映射、权限控制和导航守卫
│
├── store/                  # Vuex 状态管理
│   └── 职责：集中管理应用状态，实现组件间的数据共享
│
├── styles/                 # 全局样式
│   └── 职责：全局样式定义、主题配置和样式工具函数
│
├── utils/                  # 工具函数库
│   └── 职责：提供通用工具函数，支撑业务逻辑实现
│
├── views/                  # 页面视图
│   └── 职责：页面级组件，对应路由匹配的视图内容
│
├── App.vue                 # 根组件
├── main.js                 # 应用入口文件
├── permission.js           # 权限控制入口
└── settings.js             # 应用配置文件
```

## 目录职责总结

| 目录 | 职责 | 层级 |
|------|------|------|
| `api/` | 后端接口封装与管理 | 数据层 |
| `assets/` | 静态资源存储 | 资源层 |
| `components/` | 可复用 UI 组件 | 组件层 |
| `icons/` | 图标资源管理 | 资源层 |
| `layout/` | 整体布局结构 | 布局层 |
| `router/` | 路由配置与导航 | 控制层 |
| `store/` | 全局状态管理 | 状态层 |
| `styles/` | 全局样式定义 | 样式层 |
| `utils/` | 通用工具函数 | 工具层 |
| `views/` | 页面视图组件 | 视图层 |
